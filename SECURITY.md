# Security Policy

Maintained by `z7-codes`.

## Scope

This repository contains public, defensive, search-query patterns. It does not perform scanning or exploitation.

## Reporting a security issue in this repo

Open a GitHub issue with:

- File and line reference.
- Why the guidance is unsafe or incorrect.
- A scoped replacement suggestion.
- Source URL if available.

Do not paste real credentials, personal data, or unauthorized target findings into issues.

## Allowed use

- Assets you own.
- Assets with written authorization.
- Lab environments and CTFs.
- Public post-event writeups for learning.

## Not allowed

- Unauthorized access or data collection.
- Credential theft or credential stuffing.
- Automated mass querying of search engines.
- Exploitation of exposed admin panels.
- Downloading or storing leaked secrets.
