# Exposure Dorks — Defensive Use Only

These queries find accidentally exposed files or directories. They are included so researchers and defenders can identify exposure quickly and responsibly.

Do not download secrets, do not use credentials, do not browse deeper than needed to prove scope/impact, and do not store sensitive content.

## Directory listings

```text
site:TARGET intitle:"index of" "parent directory"
site:TARGET intitle:"index of" "last modified"
site:TARGET intitle:"index of" admin
site:TARGET intitle:"index of" backup
```

## Backup / config exposure indicators

```text
site:TARGET ext:bak
site:TARGET ext:old
site:TARGET ext:zip
site:TARGET ext:tar
site:TARGET ext:sql
site:TARGET ext:env
site:TARGET ext:ini
site:TARGET ext:conf
site:TARGET ext:config
site:TARGET filetype:env intext:"api_key"
site:TARGET filetype:log intext:"password"
```

## Public report / scan artifacts

```text
site:TARGET filetype:pdf "Nessus Scan Report"
site:TARGET filetype:pdf "Assessment Report"
site:TARGET intext:"This file was generated by Nessus"
```

## Usernames and internal identifiers

```text
site:TARGET filetype:csv intext:"username"
site:TARGET filetype:xlsx intext:"employee"
site:TARGET intext:"internal use only"
site:TARGET intext:"confidential"
```

Record only the URL and a redacted description.

## Triage

| Finding | Action |
|---|---|
| Directory listing with no sensitive files | Usually low/informational; dedupe first. |
| Backup/archive with source or config | Stop, redact, notify owner. |
| Credentials or private keys | Stop immediately; revoke/rotate; minimal redacted proof only. |
| Personal data | Stop immediately; do not copy or share. |
| Old scan report | Often Known Issue; check before reporting. |

## Handling rule

If a result appears to expose real secrets or personal data:

1. Stop further browsing.
2. Do not copy sensitive values into notes.
3. Record only: URL, timestamp, category, and redacted proof.
4. Report through the official channel.
5. For owned assets, revoke exposed credentials and recheck after removal.
