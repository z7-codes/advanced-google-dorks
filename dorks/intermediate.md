# Intermediate Dorks

Use these once beginner operators are comfortable. Goal: fewer results, better signal.

## Chaining rule

Start broad, then add one filter at a time:

```text
site:TARGET
site:TARGET filetype:pdf
site:TARGET filetype:pdf "confidential"
site:TARGET filetype:pdf "confidential" after:2024-01-01
site:TARGET filetype:pdf "confidential" after:2024-01-01 -site:TARGET/legal
```

## Date-window queries

```text
site:TARGET filetype:pdf after:2024-01-01
site:TARGET "internal use only" before:2023-01-01
site:TARGET inurl:/api/ after:2025-01-01
site:TARGET filetype:log after:2025-06-01 before:2026-01-01
```

## Noise-reduced recon

```text
site:TARGET inurl:dev -site:TARGET/blog -site:TARGET/news
site:TARGET inurl:staging -site:TARGET/careers
site:TARGET inurl:/api/ -inurl:/docs -inurl:/status
site:TARGET intitle:"login" -inurl:help -inurl:support
```

## OR pivots

```text
site:TARGET login OR signin OR sign-in
site:TARGET filetype:pdf OR filetype:docx OR filetype:xlsx
site:TARGET inurl:/v1/ OR inurl:/v2/ OR inurl:/legacy/
site:TARGET "confidential" OR "internal use only"
```

## Exposure checks

```text
site:TARGET intitle:"index of" "parent directory"
site:TARGET filetype:env intext:"api_key"
site:TARGET filetype:log intext:"password"
site:TARGET filetype:sql -inurl:download
site:TARGET filetype:pdf "Assessment Report"
```

## Parameter discovery

```text
site:TARGET inurl:?q= -site:TARGET/blog
site:TARGET inurl:?id= ext:php
site:TARGET inurl:?search= intext:"results"
site:TARGET inurl:?file= ext:php
site:TARGET inurl:?redirect= -site:TARGET/help
```

## Auth-surface inventory

```text
site:TARGET intitle:"login" -inurl:support
site:TARGET intitle:"sign in" -inurl:docs
site:TARGET inurl:/auth/ -inurl:/help/
site:TARGET inurl:/sso/ -inurl:/blog/
```

## Tech fingerprinting

```text
site:TARGET intext:"Powered by" after:2024-01-01
site:TARGET intext:"Generated by" filetype:html
site:TARGET inurl:wp-content -site:TARGET/blog
site:TARGET inurl:drupal -site:TARGET/docs
```

## Intermediate checklist

- Added at least one negative filter.
- Used one date operator.
- Used one exact phrase.
- Saved URL, query, and observation.
- Checked Known Issues before deeper work.
